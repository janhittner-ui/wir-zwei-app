Häufige Fragen

Wie verbinde ich mich mit meinem Partner?
Einer von euch legt das Paar an und findet in der App einen Einladungscode. Der andere gibt diesen Code beim Beitreten ein. Der Code gilt 48 Stunden.

Wie lösche ich mein Konto?
In der App unter Einstellungen → Konto löschen. Das geht sofort und endgültig.

Wer sieht meine Einträge?
Nur ihr beide. Zyklus-Einträge sieht dein Partner nur, wenn du das Teilen selbst einschaltest.
